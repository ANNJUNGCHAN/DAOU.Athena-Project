# app

> Terminology: [`GLOSSARY.md`](../GLOSSARY.md) is the standard vocabulary for this repo. Use its definitions; register new terms there before using them in code.

## Purpose
Athena W2 — the two-window Electron shell prototype: a canvas window (1560×800, top) and a chat
window (1560×204–788, bottom) as two OS-level independent windows. Ported from
`spike/electron-glass/v2.js`/`v3.js`/`canvas.html`. **No React, no bundler** — plain HTML/CSS/JS on
Electron 43.x. No backend wiring yet; `athena__render_canvas` exists as an IPC handler shaped like
the future MCP tool call.

## For AI Agents

### Working In This Directory
- **Surfaces: 2 persistent windows + 2 transient surfaces.** Persistent = 대화 창 (`chatWin`) and
  캔버스 창 (`canvasWin`) — both exist today. Transient = 설정창 (settings; reached from the command
  bar and from the chat window's red blink) and 팝업창 (the order-execution popup) — **neither is
  implemented yet.** `BrowserWindow` construction is limited to `warmup`/`canvasWin`/`chatWin`, and
  there are no `dialog.*` calls. Definitions: `GLOSSARY.md` §1.
- **Never use `innerHTML`.** Stream content goes through `lib/sanitize.js` and renders as text nodes;
  markdown builds DOM nodes directly. This is the rendering contract from `spike/stream-adapter/RESULT.md`.
- Autostart is gated by the `ATHENA_NO_AUTOSTART` env var, **not** `require.main === module` —
  that check is always false under `electron .` and silently produced zero windows (README bug 0).
  `verify.js` sets the var before requiring `main.js`.
- `window-all-closed` must stay an **empty handler**. Calling `app.quit()` there kills the app when
  the warmup window closes, before the real windows exist (README bug 1).
- Animated `backdrop-filter` blur must end at `0px` and clear its inline style. A residual 6px blur
  permanently blurred real data — a direct violation of `ui/soul.md` §8 (README bug 3).
- Mock data comes from `spike/captures/*.json` and is read as-is. Do not edit those captures.
- Electron's `backgroundMaterial` cannot be parameterized at runtime (on/off + type only); only
  `--glass-alpha` is adjustable. Don't reintroduce the "refraction 0.46→0.17" value as if it were settable.
- Window bounds have ±2px tolerance: acrylic windows show DPI rounding between `setBounds()` and `getBounds()`.

### Testing Requirements
```bash
cd app
npm install        # electron 43.4.0
npm run verify     # windows, screenshots, frame stats, independence, a11y, E2E, manual resize
```
Verify covers six checks; collapse animation holds ~60fps while expansion shows p95/max frame drops —
recorded honestly as a **partial pass**, not a green claim. Raw numbers in `captures/VERIFY-REPORT.json`.

### Common Patterns
- Coordinates come from real `getBoundingClientRect()`, never hardcoded.
- Expansion uses `clip-path: circle()` with blur modulation; no fades.
- The chat window grows upward only — the bottom edge with the input line stays pinned.
- Numeric columns use `--font-mono` (Geist Mono, falling back to `ui-monospace`).
