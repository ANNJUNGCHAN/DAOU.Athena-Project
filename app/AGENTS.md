# app

> Terminology: [`GLOSSARY.md`](../GLOSSARY.md) is the standard vocabulary for this repo. Use its definitions; register new terms there before using them in code.

## Purpose
Athena W2 — the two-window Electron shell prototype: a canvas window (1560×800, top) and a chat
window (1560×204–788, bottom) as two OS-level independent windows. Ported from
`spike/electron-glass/v2.js`/`v3.js`/`canvas.html`. **No React, no bundler** — plain HTML/CSS/JS on
Electron 43.x. `athena__render_canvas` is wired to decision D1's real path as of 2026-08-17:
Electron spawns `claude -p`, `lib/main/stream-json-parser.js` parses the stream-json output, and
canvas envelopes render live. The old mock path (`spike/captures/*.json` via `lib/mockdata.js`)
still exists as an **explicit fixture adapter** — it only runs when `payload.source === 'fixture'`
(see `README.md` "실배선 — claude -p ↔ 캔버스"). Default is live; only `verify.js` forces fixture
via `ATHENA_CANVAS_SOURCE=fixture` to keep automated verification quota-free and deterministic.

## For AI Agents

### Working In This Directory
- **Exactly two windows. No exceptions.** 대화 창 (`chatWin`) and 캔버스 창 (`canvasWin`).
  `BrowserWindow` construction is limited to `warmup`/`canvasWin`/`chatWin`, and there are no
  `dialog.*` calls. "설정창" / "팝업창" / "일시 표면" are **retired terms** — don't reintroduce them.
- **Everything else is a mode of the 대화 창**, implemented as a sibling panel in `chat.html`
  that shows while `#app` hides. Same resize grammar for all of them: grow to `chatMaxH`, return
  to `chatBaseH`.
  - `#onboard` → 온보딩 · 인증 (`lib/onboarding.js`, `lib/auth-screen.js`)
  - `#settings` → 설정, i.e. 계좌 · MCP cards (`chat.js` `openSettings`, `lib/settings-cards.js`).
    Entered by clicking `#dot` or via the command bar (`SETTINGS_COMMAND`); Esc returns to chat.
    The command-bar path must always exist or `ui/soul.md` §8 elimination applies.
  - 주문 확인 is the only mode still unimplemented.
  - Before 2026-08-16 the settings cards rendered in the **canvas** window. They moved because
    settings is the app itself, not data output. Old commits and captures show the canvas host.
- **Want a new window? Solve it as a mode first.** Definitions: `GLOSSARY.md` §1.
- **Never use `innerHTML`.** Stream content goes through `lib/sanitize.js` and renders as text nodes;
  markdown builds DOM nodes directly. This is the rendering contract from `spike/stream-adapter/RESULT.md`.
- Autostart is gated by the `ATHENA_NO_AUTOSTART` env var, **not** `require.main === module` —
  that check is always false under `electron .` and silently produced zero windows (README bug 0).
  `verify.js` sets the var before requiring `main.js`.
- `window-all-closed` must stay an **empty handler**. Calling `app.quit()` there kills the app when
  the warmup window closes, before the real windows exist (README bug 1).
- Animated `backdrop-filter` blur must end at `0px` and clear its inline style. A residual 6px blur
  permanently blurred real data — a direct violation of `ui/soul.md` §8 (README bug 3).
- Mock data comes from `spike/captures/*.json` and is read as-is. Do not edit those captures. This
  path only runs when explicitly selected (`source:'fixture'` in the `athena__render_canvas` IPC
  payload) — the default path is live (`claude -p` spawn, see `README.md`).
- **Never call `claude -p` from tests** — it costs quota. `lib/main/stream-json-parser.js` and
  `lib/main/claude-runner.js`'s `buildArgs` are pure/testable without spawning; their tests
  (`*.test.js`, run via `npm test`) use the S4 capture fixture instead.
- Electron's `backgroundMaterial` cannot be parameterized at runtime (on/off + type only); only
  `--glass-alpha` is adjustable. Don't reintroduce the "refraction 0.46→0.17" value as if it were settable.
- Window bounds have ±2px tolerance: acrylic windows show DPI rounding between `setBounds()` and `getBounds()`.

### Testing Requirements
```bash
cd app
npm install        # electron 43.4.0
npm test           # lib/main/*.test.js — pure parser/config unit tests, no Electron, no claude -p
npm run verify     # windows, screenshots, frame stats, independence, a11y, E2E, manual resize
```
Verify covers six checks; collapse animation holds ~60fps while expansion shows p95/max frame drops —
recorded honestly as a **partial pass**, not a green claim. Raw numbers in `captures/VERIFY-REPORT.json`.

### Common Patterns
- Coordinates come from real `getBoundingClientRect()`, never hardcoded.
- Expansion uses `clip-path: circle()` with blur modulation; no fades.
- The chat window grows upward only — the bottom edge with the input line stays pinned.
- Numeric columns use `--font-mono` (Geist Mono, falling back to `ui-monospace`).
