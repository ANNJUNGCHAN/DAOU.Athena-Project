**앱키를 복호화해서 보여주는 건 안 됩니다.** MCP 서버 설정과 계좌 앱키가 같은 암호화 방식을 쓰더라도, 복호화는 앱이 키움 API에 인증할 때 내부적으로만 수행되고 원문을 화면에 표시하는 기능은 제공되지 않습니다 — 시크릿을 평문으로 다시 꺼내 보여주는 건 암호화 저장의 목적 자체를 무력화하는 것이라 의도적으로 막혀 있는 동작입니다. 참고로 지금 설정 파일(`.mcp.json`)에는 실행 커맨드와 경로만 있고 앱키 자체는 들어있지 않습니다.

**등록이 맞는지 확인하는 올바른 방법은 실제 인증 호출을 성공시키는 것**이라 삼성전자 시세 조회를 시도했는데, athena_resolve 단계에서 서버 오류(HTTP 422/404, Selector request failed)가 반복돼 검증을 마치지 못했습니다. 키움 백엔드가 정상 기동된 상태인지 확인하신 뒤 다시 요청해 주시면, 조회가 성공하는 것으로 앱키 등록이 유효함을 바로 확인해 드릴 수 있습니다.
