## 무엇을 그렸나

유일한 출력 지점인 캔버스 창. 목업은 창 셸(1308 폭 스케일) 안에 스트림 · 리더 카드(2열)와
공통 테이블 카드(전폭), 아래 스펙 스트립(카드 슬롯 · 실배선 경로 · 확장/수축 · 실패 처리).
Spec Panel은 8개 항목(치수 · 확장 · 접기 · 픽스처 카드 3종 · 실배선 카드 3종 · 봉투 ·
카드 문법 · 정직 표기)을 적는다.

## 계약 요점 (코드 실측)

- 기본 1560×800, 화면이 작으면 균등 축소. `frame:false` — 타이틀바 없음.
- 확장: 점 좌표 기준 `clip-path: circle()` 550ms, blur 30→0px. **정지 상태 blur는 반드시 0px.**
- 접기: Esc 또는 IPC → 수축 후 `hide()`, 카드 초기화. 재확장하면 새로 그린다.
- 카드 슬롯 현행 6종:
  - 픽스처 3종 — 스트림(뉴스) · 리더(공시 원문) · 공통 테이블(재무제표).
    `ATHENA_CANVAS_SOURCE=fixture` 전용, `spike/captures` 실측 데이터.
  - 실배선 5종 — 공통 테이블(`mcp-table`) · 스트림 · 리더 · 자유 카드(`free`) ·
    알림(`notice`). 스트림·리더는 W3-lite(2026-08-17)로 실배선에 결선됐다 —
    `claude -p` 실왕복이 그리는 것은 이 5종이다. (같은 날 이전 판은 3종이라 적었다 —
    장표(35쪽)와 함께 2026-08-17에 정정했다.)
- 실배선 카드는 MCP 호출 봉투 5상태(24쪽)의 분기를 따른다. rejected · error · unparseable은
  알림 카드로 — 조용히 삼키지 않는다.
- 렌더는 전부 `textContent`/DOM 노드. `innerHTML` 문자열 삽입 0건 유지.

## 정직 표기

- 신선도(HH:MM:SS)는 표시만 하고 실시간 재갱신(폴링·WebSocket)은 없다.
- 타임라인 카드는 분기 자체가 없다(`plan/plan.md` 다음 액션 6).
- 카드 12종 체계는 초안이다(GLOSSARY §2). 공통 API 카드 6종(AT-CV-005)은 별도 설계 계층으로
  25~34쪽에 있다 — 이 장표는 그것과 경쟁하지 않고 **현재 구현된 것만** 적는다.
