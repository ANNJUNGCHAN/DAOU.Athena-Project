# AT-CH-004 — 설정 모드

- Paper node: `6A3-0` | artboard "23 · AT-CH-004 설정 모드"
- 기준일: 2026-08-17 · 성격: **구현 실측 장표** — 설계를 먼저 그린 것이 아니라 이미 동작하는
  코드를 장표로 옮겼다. 원본은 `app/lib/settings-cards.js` · `app/chat.js` · `app/chat.html`이다.

## 무엇을 그렸나

대화 창이 설정으로 변한 상태. 새 창이 아니다 — `#app`이 물러나고 형제 패널 `#settings`가
나타나며 창이 `chatMaxH`(788)로 자란다. 목업은 유리 패널 + 계좌 카드 + MCP 카드 2장,
Spec Panel은 8개 항목(진입 · 모드 배타성 · 창 동작 · 카드 2장 · 시트 오버레이 · Esc 규칙 ·
비밀값 · 출처)을 적는다.

## 계약 요점 (코드 실측)

- 진입: `#dot` 클릭 **또는** 커맨드바 "설정" 정규식(`SETTINGS_COMMAND`) — 점은 추가 진입로다.
- 모드 배타성: `#app` · `#onboard` · `#settings` 중 정확히 하나만 보인다(`[hidden]` 강제).
- Esc 우선순위: 설정 닫기 › 진행 중 질의 중단 › 캔버스 접기 (`app/chat.js` Escape 핸들러).
- 시트(등록 · 주문 API 게이트 · 스니펫 분석 · probe)는 카드 내부 오버레이다. 새 창 금지.
- 비밀값: APP KEY 마스크, SECRET은 문자 수만. MCP env는 키 이름만 노출.
