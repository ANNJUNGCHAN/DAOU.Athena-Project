# Athena 카드 템플릿 — 애드혹 차트 카탈로그

최종 갱신: 2026-08-18 · 브랜치: AITS-화면

Paper 파일: **"Athena — 카드 템플릿"** (`https://app.paper.design/file/01M091F3WSATWRCVACK8069YEM`)
— 화면설계서와 **별도 파일** (사용자 지시, 2026-08-18).

## 왜 있는가

TR에 매칭된 화면은 manifest가 즉시 불러온다(공통화면의 강점). 이 카탈로그는 그 밖의 요청 —
**"~그래프로 그려줘"** — 에 답하는 표현 템플릿이다. Tableau의 "일반 차트 유형 작성"급 커버리지
+ 증권 특화를 목표로 한다(사용자 참조: Tableau desktop_einstein / dataview_examples).

**카드 12종은 늘지 않는다.** 전부 기존 카드(주로 CompoundCard) 위 **렌즈 변형**이다 —
차트 렌즈 계약([`chart-lens-spec.md`](chart-lens-spec.md))과 같은 층위.
차트 카드 컨트롤(주기·차트모양·보조지표 35종·매물대·드로잉·수정주가·전체화면·수치조회창)의
동작 전수는 [`chart-card-control-spec.md`](chart-card-control-spec.md)가 계약 기준이다.

## 확정 규범 (템플릿 전 장 공통)

- **유리는 손으로 그린다** (화면설계서 아트보드 28 확립 관례 — Paper는 backdrop-filter 미렌더):
  데스크톱 `#0D1016`(광량 1단) 위에 흡수 그라디언트 카드
  `linear-gradient(180deg, rgba(41,47,59,0.78), rgba(30,35,45,0.68))` · 윤곽 `rgba(255,255,255,0.07)` 1px ·
  radius 16px · 상단 엣지 하이라이트(inset 0 1px rgba(255,255,255,0.07)) + contact shadow
  (0 24px 56px rgba(0,0,0,0.45)) — **깊이는 테두리 굵기가 아니라 값으로**.
- **카드 크롬**: 제목(Daki B, letter-spacing 0.3px) + 갱신 시각 타임스탬프(Geist Mono 11px
  "MM.DD HH:MM 기준") + 무채색 유리 칩.
- **AITS 실물 계승** (2차 실측 = chart-lens-aits-survey.md 부록 C): 차트 카드 툴바(주기 탭
  일·주·월·년·분·틱 + 차트모양▾ + 보조지표▾ + 수정주가 + 전체화면, 드로잉은 전체화면 전용),
  매물대 = 보조지표 패널 토글(우측 34% 오버레이, POC만 적색 강조), 호가창 = 10단 사다리
  (매도 위 파랑·매수 아래 빨강, 잔량 막대 좌우 대칭, 현재가 단계 테두리 강조), 거래량은
  하위 패널 분리, 가격축 우측, 그리드 `rgba(120,128,140,0.12)`.
- **이중축 금지** — 스케일이 다르면 패널 분리(13) 또는 기준일=100 정규화(17).
- **등락 시맨틱**: 상승 `#FF5C5C` 빨강 · 하락 `#4D9FFF` 파랑 (한국 관례, palette.md 확정) —
  시리즈 색으로 재사용 금지.
- **카테고리 시리즈 3색 고정 순서**: `#3D87E0 → #C07E30 → #B76BD4`.
  dataviz validator로 dark 표면(`#171B24`) 대비 전 검사 통과(2026-08-18 실행 — lightness band
  L 0.48–0.67 · chroma · CVD ΔE · normal-vision · contrast 전부 PASS). 4번째 시리즈부터는
  "기타"로 접는다 — 색 생성 금지.
- **다이버징(16)**: up/down 양극 + 중립 `#262C37` 미드포인트.
- 축·숫자 `Geist Mono` 11px `#6B7480` · 한글 라벨 `Daki` · 텍스트에 시리즈 색 금지 ·
  색 단독 식별 금지(≥2 시리즈는 범례+직접 라벨) · 막대 간격 ≥2px · 선 2px.
- 브랜드색(`#EE137B`) 데이터 인코딩·장식 사용 0건 (soul.md §4·§7).

## 미해결·후속

- 템플릿 → 실제 렌더러 구현은 차트 렌즈 구현 라운드 소관 (chart-lens-spec §7과 합류).
- 셀렉터가 질의→템플릿을 고르는 라우팅 규칙(결정적·설명 가능)은 미설계 — 별도 라운드.
- Tableau 목록 중 의도적 제외: 맵(국내 증권 무관), 간트(일정 데이터 없음), 파레토(수요 확인 후),
  상자수염(분포는 05 히스토그램이 1판 커버).
