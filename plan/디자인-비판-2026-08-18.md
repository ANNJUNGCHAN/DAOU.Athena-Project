## 1. 확정된 지적 (적대적 검증 통과)

### ① [심각 5] "모든 표면이 유리다"가 캔버스 카드 1곳에만 구현돼 있었다
`backdrop-filter`는 `canvas.css .card` 둘뿐 — 설정 카드(`settings-cards.css .card` 알파 0.7 평면),
시트(`uk-sheet` 솔리드), cmd-box, 온보딩 CLI 카드, 인증 타이머 카드 전부 굴절 없는 평면 rgba.
soul.md §7 금지 목록 "유리를 장식으로 쓰기"에 정확히 해당. 앱이 가장 오래 머무는
모드(온보딩·인증·설정)의 카드가 전부 가짜 유리였다.
→ **즉시 수정**: 6개 표면에 카드 표준 재질(알파 0.45~0.62 + blur 14~18px) 적용,
`access.css` reduced-transparency 폴백에 신규 표면 6종 추가.

### ② [심각 4] Paper 화면설계서가 자기 규범을 안 지켰다 — 갱신 7개 보드 외 전부 구식 레시피
"구현됨" 배지가 붙은 보드(13 계좌 목록 등)조차 94% 불투명 + backdrop-filter 0건.
검증자가 Paper MCP로 직접 재현 확인. 같은 문서를 펼치는 쪽에 따라 정반대 재료 지시.
→ **즉시 수정**: 구형 레시피 노드 **55개 전수 색출·일괄 교체**(창급 25 · 행급 4 ·
솔리드 10 · 평면 Desktop 배경 14). 이제 화면설계서 전체가 부록 A2 수치와 일치한다.

### ③ [심각 2 하향] "대비는 유리 두께로 확보한다"의 두께를 같은 날 63% 깎으면서 밝기 감지가 없다
반박자가 심각도를 5→2로 조정 — acrylic 네이티브 블러와 prefers-contrast 폴백(캡처 검증됨)이
이중 방어로 남아 있음을 확인. 다만 **밝은 배경 자동 적응 미구현 + 밝은 배경 회귀 캡처 0건**은
사실 → 권고로 남김(아래 §4).

## 3. 반박된 지적 5건 — 왜 기각됐는가 (교훈 포함)

1. **"렌즈·스펙큘러 0건, 단일 알파 사각형"** — `capturePage()`는 OS 합성(acrylic 굴절)을
   원리적으로 못 찍는다. 저장소 자신의 스파이크(S1-b 쌍)가 이미 증명한 함정에 빠진 지적.
   ※ CLAUDE.md §8 함정 목록 그대로 — **캡처 근거 지적은 항상 03c류 OS 합성 캡처로 재검증할 것.**
2. **"굴절 대상이 손으로 그린 그라디언트뿐"** — 같은 함정. 그라디언트는 acrylic 위 보조 레이어.
3. **"광량 3단이 9/255 차이로 소멸"** — 알파 채널(위계 신호 그 자체)을 버리고 RGB만 비교한
   측정 오류. 올바르게 합성하면 채널당 ~50 델타.
4. **"idle 점의 마젠타 글로우는 '빛은 데이터에만' 위반"** — palette.md가 명문화한 예외
   ("마젠타는 지금 입력을 받는 자리 정확히 한 곳")의 구현체.
5. **"liquid-glass §3 vs soul §7 충돌 은폐"** — plan.md·스파이크 RESULT.md가 이미
   '미채택·재계측 대기'를 정직하게 기록 중. 문서 역할 분리를 놓친 지적.

## 4. 남은 권고 (철학·설계급 — 무승인 실행하지 않음)

- **[높음] 자유 리사이즈의 발견 가능성 부재** — 리사이즈 가능함을 알리는 시각 신호 0개.
  그립(y:0~10)과 OS 네이티브 엣지 리사이즈의 픽셀 충돌, □ 토글이 사용자 커스텀 높이를
  조용히 지우는 상태 기계 미비까지 한 묶음. 별도 설계 세션 필요(코치마크·커서·hit-test).
- **[높음] 광량 3단 규칙 vs 실제 4값(0.30/0.45/0.50/0.55)** — "같은 단계끼리 값이 같아야
  한다"는 완화책이 값 체계와 안 맞는다. 3단의 SSOT(CSS 변수 3개) + verify 단언으로
  고정하든가 규범을 4값 사다리로 개정하든가 — 결정 필요.
- **[높음] 폰트 크기 토큰 부재** — 9.5~15px 사이 0.5px 단위 임의값 12종. 유한 스케일
  (--font-size-*) 정의 + 전 CSS 치환은 규모가 커서 별도 작업으로.
- **[중간] 설정 진입(점·커맨드바) 무발견** — soul.md "설정을 찾아 헤매지 않는다"를 스스로
  통과 못함. 1회성 코치마크 또는 빈 이력 추천 칩.
- **[중간] 명도 위계 이원화** — k-dim/faint 2단 vs 온보딩·설정의 11단 알파 리터럴.
- **[중간] Paper 데스크톱 배경이 '무대 세트'** — 실제 밝은 배경화면·아이콘 조건의 검증
  보드 1장 필요(palette.md 감지-적응 미구현과 같은 뿌리).
- **[중간] 모자이크 재배치(카드 사이) 명세 부재** — 카드 내부 fold는 숫자 스펙인데 카드
  간 재배치는 문장 1줄. 전용 보드 필요.
- **[낮음] FactsCard 보드 "미해결" 텍스트 vs 확정된 목업 픽셀** — 유리화 일괄 갱신으로
  픽셀은 유리가 됐으나 "미해결" 선언 자체의 해소는 결정 대기.
