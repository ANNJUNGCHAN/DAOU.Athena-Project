## Goal

Athena의 화면 구조를 **Codex 데스크톱 레퍼런스와 같은 단일 창 3영역**으로 재설계하고,
알림을 **데스크톱 구석 상시 원형 오브**로 분리한다. 이번 작업의 산출물은
**Paper 신규 워크스페이스의 핵심 5장 + 실현가능성 판단서**이며, 구현은 그 결과를 보고 결정한다.

확정된 레이아웃:

```
┌──────────────┬───────────────────────────┬──────────────┐
│ 좌: 대화 이력 │ 중앙: 캔버스(카드 12종)     │ 우: 채팅      │
│  · 새 대화    │  · 표·차트·facts·compound  │  · 입력      │
│  · 날짜별 목록│  · 카드가 쌓이는 주 무대     │  · 답변 흐름 │
│  · 하단 설정  │                           │              │
└──────────────┴───────────────────────────┴──────────────┘
     ↕ 접힘                                    (항상 표시)
설정 진입 시 → 창 전체가 설정 화면으로 스왑(← 앱으로 돌아가기)

        ◯  ← 데스크톱 구석 상시 원형 오브(별도 창)
```

## Constraints

- **디자인 언어는 2026-08-22 확정본을 그대로 계승한다** — 투명창 · 백색 유리 · 잉크 텍스트 ·
  대각선 스펙큘러 없음 · 유리 사다리 순서 계약(window < card < canvas < window-max) ·
  설정의 유리 투명도 3단(clear/default/opaque) · 글자 크기 5단계.
- **기존 Paper 화면설계서 70여 보드는 그대로 계승한다.** 새 워크스페이스는 셸 레이아웃만
  새로 그리고 카드 내용물은 기존 보드를 인용한다. **카드는 12종 고정** — TR이 늘어도 안 늘린다.
- **규범 문서를 이번에 개정한다** — `GLOSSARY.md:201`, `CLAUDE.md:53`, `ui/soul.md:267`의
  "상시 사이드바·탭바·툴바 = 즉시 탈락" 조항과 "창은 둘뿐" 정의를 새 구조에 맞게 고친다.
  문서와 그림이 처음부터 일치해야 한다.
- **오브에 실행 버튼을 달지 않는다.** `CLAUDE.md §1` 확정 결정 3 — 감시 에이전트는 알림까지만,
  주문은 사람이 낸다. 오브의 액션은 "앱에서 열기 / 더보기"까지다.
- **알림 발생원은 셋** — ① 앱 상태 ② 사용자가 승인한 감시 조건 도달 ③ (후속) 투자 브레인 추천.
- 오브 확장 시 문구는 **대화체**이며, 능동 턴의 정직성 계약(발화 배지 · 방식 표기 · 소스 라벨 ·
  시점 고지)을 유지한다.
- Paper 저작은 **Paper MCP 재연결 이후**에만 가능하다(아래 §차단 요인).

## Non-Goals

- **구현은 이번 범위가 아니다.** Paper 5장 + 판단서에서 끝난다.
- 투자 브레인 기반 자동 추천 알림은 후속(설계에 자리만 남긴다).
- 오브에서 직접 질의하는 미니 입력창은 넣지 않는다(커맨드바 단일 입력 원칙 유지).
- 기존 70여 보드의 재저작.
