# Athena 3일 실사용 베타테스트 프로토콜

## 목적

한 시간마다 짧게 앱을 확인하는 1,000만원 단타 슬리브와, 5,000만원~1억원 규모의 장기·중기 슬리브가 앱 안에서 섞이지 않는지 72시간 동안 실제 UI 조작으로 검증한다. 미국 시장은 ETF 장기 적립식, 한국 시장은 대형주·ETF 중기 운용을 기준으로 하며, 적립식이라도 투자 논리가 훼손되면 전술적으로 비중을 줄이는 사용자다.

## 안전 경계

- 조회, 분석, 차트, 그래프 탐색은 수행한다.
- 알림은 초안, 검토, 승인, 수정, 일시정지, 재개, 삭제 흐름을 검증한다.
- 주문은 티켓과 확인 경계까지만 확인하고 실행 버튼을 누르지 않는다.
- 실계좌 주문, 모의계좌 주문 API, 계정 변경, 외부 전송은 수행하지 않는다.
- 플러그인은 실제 런타임 연결과 UI 세션 초안을 구분한다. 승인 없이 설치나 권한 저장을 하지 않는다.
- 모든 세션에서 `broker_mutation_count=0`을 유지한다.

## 운영 리듬

- 전체 기간: 2026-08-31 01:24 KST 이후 최소 72시간.
- heartbeat: 한 시간 간격, 72회 계획. 누락은 숨기지 않고 사유를 기록한다.
- 국장 장중: 09:05, 10:00, 11:00, 12:00, 13:00, 14:00, 15:00, 15:40 KST 중심.
- 장기 포트폴리오: 20:30 KST.
- 미장 ETF: 22:20, 23:30 KST와 익일 07:30 KST.
- 각 세션은 질문 1개 이상, 후속 질문 또는 기능 전환 1개 이상, 스크린샷 1개 이상을 남긴다.

## 날짜별 초점

### Day 1 — 단타 루프와 첫인상

- 삼성전자, SK하이닉스, KODEX 200을 한 시간 단위로 볼 때 필요한 가격, 거래량, 호가, 수급 정보를 질문한다.
- 5분/60분 흐름, 직전 세션 대비 변화, 알림 초안, 주문 티켓 안전 경계를 검증한다.
- 채팅 실패와 데이터 미연결 상태가 사용자에게 정직하고 복구 가능하게 표시되는지 본다.

### Day 2 — 장기 적립, 국장 중기, 그래프와 플러그인

- 미국 ETF를 S&P 500, 나스닥 100, 배당 역할로 비교하고 3년 이상 관점의 위험을 묻는다.
- 삼성전자 일봉/주봉과 수급을 단타 관점과 중기 관점으로 분리한다.
- 그래프 요약, 지도, 노드 상세, 채팅 복귀를 순회한다.
- DART, Google Sheets, 텔레그램 알림, 실적 캘린더의 검색, 권한, 설치 미리보기를 확인한다.

### Day 3 — 전술적 축소와 실패 복구

- 장기 ETF 급락 시 현금 유지와 적립 판단 프레임을 묻는다.
- 국장 중기 보유분 축소 조건을 가격, 수급, 실적으로 나눈다.
- 중복 알림, 앱 재시작 후 지속성, 오래된 데이터, 애매한 시간축, 빠른 종목 전환, 응답 중단을 검증한다.
- Day 1 질문을 다시 실행해 기억, 일관성, 그래프 변화를 비교한다.

## 세션 증거 필드

`evidence_id`, `timestamp_kst`, `elapsed_hour`, `market_state`, `persona_sleeve`, `session_goal`, `exact_utterance`, `start_surface`, `end_surface`, `computer_actions`, `expected_behavior`, `actual_behavior`, `data_provenance`, `data_as_of`, `latency_ms`, `continuity`, `safety_boundary`, `broker_mutation_count`, `alert_lifecycle`, `plugin_state`, `trust_score_1_5`, `friction_score_1_5`, `severity`, `repro_steps`, `evidence_refs`, `workaround`, `status`, `recommended_owner`를 기록한다.

## 완료 게이트

- 실제 경과시간 72시간 이상.
- 매시간 checkpoint 또는 명시적인 누락 사유가 있는 72개 시간 슬롯.
- 자연어 질문 30개 이상, 후속 질문 15개 이상.
- 단타, 국장 중기, 미장 장기, 전술적 축소 각각 5턴 이상.
- 그래프 6회 이상, 미장 ETF 세션 6회 이상, 숨김/복원 또는 재시작 6회 이상.
- 서로 다른 목적의 알림 초안 4개 이상과 전체 수명주기 검증.
- DART, Sheets, 텔레그램 알림, 실적 캘린더 4개 경로 검증.
- 주문 실행 0회, broker mutation 0건.
- live, cache, fixture, UI draft, unknown을 최종 보고서에서 분리한다.
- 모든 Major 이상 결함에 재현 절차와 화면 증거가 있다.

72시간이 지났다는 사실만으로 완료하지 않는다. 위 근거가 부족하면 목표는 계속 활성 상태로 둔다.
