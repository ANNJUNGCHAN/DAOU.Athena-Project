# 실시간 오류 수정 기록

> 역사적 작업 기록이다. 이후 부모 커밋에서 금 티켓 단위가 g로 바뀌었다. 현재 인계 상태와 개/주→g 의미 불일치, 다음 작업은 `2026-09-09-grok-realtime/README.md`를 우선한다. 아래 1개 캡처 기록은 이전 코드의 검증이며 최신 단위 검증이 아니다.

## 주문 팝업과 금 시세

- 금현물 시장가 매수 요청의 상품·수량을 대화별로 이어받아 주문 초안을 연다. 시세 조회 성공을 팝업 표시의 선행 조건으로 사용하지 않는다.
- `주문 화면이 안열려`, `주문 팝업이 안뜬다`, `주문창 안떠`도 완성된 초안을 다시 여는 요청으로 처리한다.
- 금현물 시장가 매매구분 코드를 현재 API 계약에서 확정하지 못했으므로 실행 버튼은 제한 사유와 함께 비활성화한다. 임의 코드를 만들어 주문하지 않는다.
- 실제 Electron 주문 팝업 검증에서 상품·수량 1개·제한 사유를 확인했다. 계좌 조회, 주문 가능 수량 조회, 주문 실행은 각각 0회였다. 증거: `app/captures/probe-gold-order-ticket.png`, `app/captures/probe-gold-order-ticket-report.json`.
- 금 시세 실패의 재현 원인은 HTTP 422 `CANVAS_COVERAGE_MISSING`이었다. `base:ka50100` 응답의 전송 메타데이터 `return_code`를 표시 필드로 처리하면서 공개 라벨을 찾지 못했다. 화면 정의의 제외 필드를 투영에 적용했다. 업무 필드 검증과 진단용 원본은 유지한다.
- 수정 후 실행 중 백엔드에 `금 99.99 1kg 현재가 알려줘`를 재요청하여 HTTP 200, `rendered`, `base:ka50100`을 확인했다(671ms). 모든 도구 실패를 게이트웨이 오류로 표시하던 문구도 원인별 진단으로 교체했다.
- 상품을 지정하지 않은 `금현물 시세 알려줘`에는 로컬에서 1kg과 미니금 중 하나를 묻는다. 선택을 받으면 상품 코드를 명시한 정상 조회로 이어진다. 선택 후 실제 생성되는 1kg 질의도 HTTP 200으로 확인했다(4845ms). 이를 게이트웨이 장애로 해석하거나 임의 상품을 선택하지 않는다.

## 종목 찾기

- 거래대금 정렬, 필터 행 선택, 전체 칩 클릭 영역, 하이드레이션 후 이벤트 재연결, 시간외 단일가에서 정규장으로 돌아오는 경로를 수정했다.
- 보드별로 의미가 반대인 유동성 포함 인자를 각각 해석하도록 수정했다.
- 실제 Electron 8개 보드 클릭 검증에서 차단된 클릭 0건. 증거: `app/captures/paper-gates/CARD-BUTTONS-ranking-review.json`.
- 시가총액 조건은 해당 순위 API가 필요한 값·조건을 제공하지 않아 지원 불가 사유를 표시한다. 적용되지 않은 필터를 적용됐다고 표시하지 않는다.

## 플러그인과 부엉이

- 추천 목록, 추천 설치 기능, 강조된 안내 문구와 설치됨 제목을 제거했다. 직접 서버 추가와 기존 플러그인 권한·관리 기능은 유지한다.
- 채팅 하단 부엉이의 크기 확대·축소 효과를 제거했다.

## 기법 생성과 편집기

- 기본 예제 목록을 제거하고 실제 등록한 사용자 기법을 표시한다.
- 새 기법은 팝업에서 프로젝트·부모 폴더·기법명을 지정한 뒤 프로젝트 내부에 새 하위 폴더를 만든다. 절대경로·상위 경로 탈출·심볼릭 링크 우회를 검증한다.
- 생성한 기법은 목록 메타데이터에 등록하고 새 대화에서 연다. 등록은 실행·활성화·배포와 별개다.
- 파일 탐색기, 편집 탭, 터미널을 연결한다. 설정·문서 등 텍스트 파일도 편집하며 바이너리는 읽기 전용 정보로 표시한다. 삭제 요청한 제어 모드·수동 환경·승인 안내 영역을 제거한다.
- 환경 준비는 생성 시 자동으로 시작한다. 시작 실패 시 새로 만든 기법 폴더를 롤백하여 재시도할 수 있다.
- 채팅의 `write_file`은 실제 디스크 저장 완료를 기다린 뒤 성공을 반환한다. 완료 이벤트는 현재 프로젝트·기법 루트와 일치할 때 편집기에 반영하며 중복 저장하지 않는다.
- 터미널은 프로젝트 안의 작업 디렉터리와 인자 배열을 사용하며 출력·종료 코드를 표시한다. 임의 프로그램의 파일 접근까지 차단하는 운영체제 샌드박스는 아니다.
- 자동저장과 프로젝트 전환의 지연 응답 경합을 방지한다. 채팅 전송·대화 이동 전에 미저장 탭을 저장한다. 채팅이 파일을 변경하는 동안 편집기는 읽기 전용이며 턴 종료·오류 시 잠금을 해제한다. 동시 턴은 각각의 소유자로 잠금을 관리한다.
- 별도 Electron 시각 검증에서 탐색기·편집기·터미널과 삭제 영역 0건을 확인했다. 증거: `.omc/artifacts/project-ide-overhaul.png`. 이 화면은 레이아웃 검증용 파일과 결과 형식을 사용하며 실제 백테스트 성과 증거가 아니다.
- 대화 작업공간에 프로젝트·기법 루트·활성 파일을 저장하고 복원한다. 등록된 기법은 ID·프로젝트·파일 경로를 현재 등록부와 대조한 뒤 연결한다. 프로젝트가 없어졌으면 폼·코드·로그를 보존하며 실패 원인을 표시한다.

## 적용 범위

백엔드의 금 시세 수정은 실행 중 서비스에서 확인했다. Electron UI와 주문 경로는 수정된 소스를 사용하는 별도 검증 프로세스에서 확인했다. 기존 실행 중인 Electron 프로세스가 새 main 코드를 읽었다고 보장하지 않는다. 실제 사용자 앱에는 재실행이 필요하다. 실제 주문은 전송하지 않았다. 커밋·푸시는 수행하지 않았다.
