## 브랜치에서 수정한 내용

- 코드 감시 초안을 저장하기 전에 프로젝트 폴더, 코드 파일, 내용 해시를 확인한다. 파일이 없는 초안은 저장하지 않는다. 실행기 연결이 없더라도 유효한 파일의 초안 작성은 허용한다.
- 프로젝트 미등록, 폴더 없음, 코드 파일 없음, 접근 오류, 해시 불일치를 구분한다. 폴더가 없는 경우 파일 저장 요청으로 삭제된 프로젝트를 암묵적으로 복원하지 않는다.
- 캔버스 승인 버튼도 채팅 카드와 동일하게 활성화 차단 사유를 표시하고 비활성화한다. 상세 응답의 최신 값이 목록의 이전 값보다 우선한다.
- 복구 대화에 알람 식별자, 오류 사유, 파일 참조, 기존 조건과 설정을 전달한다. 코드 감시 수정은 에이전트 모드로 연결하며, 입력 준비만 하고 자동 제출하거나 승인하지 않는다.
- 현재 선택된 프로젝트의 실제 폴더만 사용한다. 다른 과거 프로젝트를 목록 첫 행이라는 이유로 선택하지 않는다.
- 진행 상태는 실제 활성 감시 수로 계산한다. 최초 로딩과 조회 실패를 감시 0건으로 표시하지 않고, 재조회 실패 시 마지막으로 읽은 목록을 보존한다.
