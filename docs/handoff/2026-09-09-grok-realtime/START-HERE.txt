이 저장소의 실시간 오류 수정 작업을 이어서 진행해 줘. 먼저 루트 GROK.md와 docs/handoff/2026-09-09-grok-realtime/README.md를 읽고 현재 브랜치·HEAD·변경사항을 확인해.

대상 브랜치는 codex/grok-realtime-handoff-20260909이다. 과거 .omc나 Codex 세션에 접근할 필요 없이 이 브랜치만으로 이어갈 수 있어야 한다. 이미 구현된 기능을 처음부터 다시 만들지 말고 인계 문서의 현황과 실제 코드를 대조해.

첫 작업은 금현물 주문 초안에서 '1개/1주'가 숫자 그대로 '1g'로 바뀌는 단위 불일치 수정이다. 임의로 무게를 환산하지 말고 g 단위의 명시적 수량을 받도록 해. 잘못된 기존 테스트 기대값도 의미에 맞게 고쳐. 금 주문 실행 차단은 API 계약과 별도 실행 권한이 확인되기 전까지 유지해.

그다음 종목 찾기 정렬/필터/정규장 전환, 플러그인 추천 제거, 실제 기법 목록, 새 기법 폴더·이름 선택→프로젝트 내부 생성→등록→새 대화, 전체 파일 편집기·자동 환경·터미널·채팅, 대화 A→B→A 복원, 부엉이 크기 이펙트 제거, 금 시세 조회와 주문 팝업을 실제 앱에서 검증하고 발견되는 오류를 수정해. 새 기법 폴더는 프로젝트 밖으로 나가면 안 돼.

환경·인증이 없으면 먼저 코드와 결정론 테스트를 검증하고, 필요한 비밀값은 Git이나 채팅에 출력하지 말고 안전한 로컬 설정에서 받도록 해. 가격·테스트 결과·실행 성공을 지어내지 마. 실제 주문을 테스트 목적으로 전송하지 마.

수정→타깃 테스트→독립 검토가 가능하면 검토→전체 테스트→실제 화면 확인 순서로 진행해. Codex 전용 도구가 없다면 일반 파일/터미널/Git 도구로 대체해. 인계 당시 테스트 통과 숫자를 현재 결과로 재사용하지 마. 작업 결과와 남은 문제를 인계 README에 갱신하고, 사용자의 다음 실시간 오류도 같은 작업 흐름으로 계속 처리해.
