# Athena 제품 페이지

최종 원고를 여섯 제품 페이지에 반영했습니다. 첫 번째 주요 기능은 넓은 화면 이미지로, 다음 두 기능은 나란히 배치했습니다. 서브 기능은 아이콘과 설명으로 구성했습니다.

[index.html](index.html)을 브라우저에서 열면 모든 페이지를 살펴볼 수 있습니다. 별도 설치나 서버가 필요하지 않습니다. 각 페이지의 화면 이미지를 누르면 확대되고, Esc로 닫을 수 있습니다.

| 제품 | 페이지 | 주요 기능 | 서브 기능 |
| --- | --- | ---: | ---: |
| 아고라 | [agora.html](agora.html) | 3 | 2 |
| 메티스 | [metis.html](metis.html) | 3 | 2 |
| 아이기스 | [aegis.html](aegis.html) | 3 | 0 |
| 에르가네 | [ergane.html](ergane.html) | 3 | 0 |
| 팔라스 | [pallas.html](pallas.html) | 3 | 2 |
| 글로우 | [glow.html](glow.html) | 3 | 0 |

원고는 [확정 원고](../audits/2026-09-10-product-page-copy.md)의 소개문, 기능명, 설명을 공백까지 그대로 사용했습니다. 웹페이지는 정적 HTML이므로 이후 원고를 수정하면 해당 HTML에도 반영해야 합니다.

구성은 [Google Antigravity 제품 페이지](https://antigravity.google/product/antigravity-2)의 넓은 여백, 중앙 소개, 큰 화면 이미지와 아래 설명, 아이콘 기능 영역을 참고했습니다. 흰색 배경과 한 가지 강조색을 사용하고, 이미지 영역에만 옅은 색 번짐을 넣었습니다. 움직임은 탐색과 확대에 대한 짧은 반응으로 제한했습니다.

화면 이미지는 저장소에 있는 앱 캡처와 Paper 시안입니다. [assets.json](assets.json)에 각 기능의 원본 경로와 표시 범위를 기록했습니다. 원본 파일은 편집하지 않았고 CSS로 필요한 영역을 보여줍니다. 이미지는 ../../app, ../../artifacts, ../handoff 경로를 참조하므로 다른 위치로 옮길 때 이 자산도 함께 보존해야 합니다.

전용 캡처가 없는 경험은 가까운 기존 화면을 사용했습니다.

- 메티스의 맞춤 추천은 추천 근거가 되는 관심사·활동 요약 화면입니다.
- 아이기스의 통합 감시는 개별 감시 작업의 실행 결과 화면입니다.
- 에르가네의 서비스 연동은 텔레그램 연결 화면이며 모바일 대화 장면은 포함하지 않습니다.
- 에르가네의 도구 호출은 아고라에서 @로 도구를 지정한 대화 예시입니다.
- 팔라스의 백테스트는 성과·거래 횟수가 보이는 Paper 결과 화면이며 자산곡선·체결표·전략 비교 장면은 포함하지 않습니다.
- 글로우의 미니 대화는 대화 시작 상태이고, 화면 질문은 자료와 채팅을 함께 보여주는 예시입니다. 영역 선택 장면은 포함하지 않습니다.

이 화면 선택은 기능별 소개 페이지의 배치를 완성하기 위한 것입니다. 확장 기능은 사용자가 확정한 원고대로 소개하며, 캡처에 표시된 과거 수치와 상태는 현재 투자정보나 현재 서비스 상태를 뜻하지 않습니다.

검증 결과는 [verification.json](verification.json)에 기록했습니다. 여섯 제품의 원고 일치, 18개 주요 이미지와 6개 서브 아이콘 로드, 전체 목록을 포함한 7개 페이지의 1440·768·390·320px 배치, 모바일 탐색, 확대 보기와 키보드 동작, 파일 직접 열기를 확인했습니다. *-desktop.png와 *-mobile.png는 각 페이지의 검증 시점 전체 화면입니다.

글꼴과 아이콘은 로컬에 포함되어 외부 네트워크를 요구하지 않습니다. Pretendard와 Tabler Icons의 출처 및 라이선스는 [LICENSES.md](LICENSES.md)에 있습니다.
