# Athena 6개 제품 소개 — 아이디어 대회용 기획 원고

> 최종 제목·설명·기능 편성은 [제품 페이지 원고](C:/Projects/DAOU.Athena/docs/audits/2026-09-10-product-page-copy.md)를 사용합니다. 아래는 정제 이전의 기능 후보와 화면 구상, 조사 근거를 보존한 기록으로, 이후 병합·재배치·제외된 소개 항목도 포함합니다.

2026-09-10 · 최신 사용자 피드백 반영

이 문서는 **아이디어 대회에서 보여줄 완성된 제품 경험**을 설명한다. 소개 문구는 모두 현재형으로 썼으며, 코드·Paper에서 확인한 기반에 사용자가 지정한 방향과 신규 아이디어를 더했다. 현재 출시 기능의 검증 보고서는 아니다. 기존 조사 근거와 이번 기획의 관계는 문서 끝에 정리했다.

## 1. 여섯 제품을 관통하는 이야기

**대화로 시작한 일이 나만의 지식으로 쌓이고, 그 지식이 다음 추천과 알림으로 돌아옵니다.**

아고라에서 질문하고, 에르가네로 필요한 도구를 연결합니다. 팔라스에서는 투자 아이디어를 대화로 만들고 백테스트합니다. 메티스는 이 모든 활동을 연결해 나를 이해하고, 아이기스는 그 맥락에 맞는 변화를 감시합니다. 글로우는 다른 일을 하는 동안에도 질문과 결과를 곁에서 이어줍니다.

| 제품 | 메인 수 | 서브 수 | 이 페이지에서 전달할 약속 |
|---|---:|---:|---|
| 아고라 | 3 | 3 | 필요한 창부터 주문까지, 대화로 이어가는 작업 |
| 메티스 | 4 | 5 | 앱의 모든 활동이 내 지식이 되고, 그 지식으로 대화하고 추천받는 경험 |
| 아이기스 | 3 | 3 | 나를 이해하는 그래프와 연결된 도구를 바탕으로, 말로 만드는 감시와 알람 |
| 에르가네 | 3 | 5 | 투자정보와 외부 서비스를 연결해 모든 모드에서 나만의 도구로 활용 |
| 팔라스 | 5 | 3 | 직접 코드를 쓰지 않고, 대화로 전략을 만들고 백테스트하는 바이브코딩 |
| 글로우 | 4 | 3 | 작업 화면 곁에서 맥락을 받아 질문하고, 중요한 변화를 확인하는 작은 동반자 |
| 합계 | 22 | 22 | 서브는 모두 홀수. 아고라와 아이기스는 최신 지정에 따라 메인·서브 각 3개 |

메인은 큰 앱 이미지로 보여줄 독립된 경험, 서브는 아이콘과 짧은 문구로 설명할 추가 가치를 담는다. 위치 이동·접기·필터·다시 열기처럼 일반적인 조작은 대표 기능에서 제외했다.

## 2. 아고라 — 대화가 작업이 되는 곳

**헤드라인: 찾던 화면도, 다음 행동도. 말로 이어가세요.**

원하는 정보를 말하면 필요한 창이 열립니다. 보고 있는 결과에 질문을 이어가고, 주문까지 같은 대화에서 준비하세요.

### 메인 3개

| ID | 제목 | 소개 문구 | 큰 이미지에 담을 장면 |
|---|---|---|---|
| Q1 | 말하면 필요한 창이 열립니다 | 차트, 시세, 공시처럼 지금 필요한 정보를 말하세요. 질문에 맞는 창이 열리고, 다음 질문에 필요한 자료도 대화 속에서 이어집니다. | “이 종목의 차트와 최근 공시를 보여줘”라는 질문과 생성된 결과 창 |
| Q2 | 보고 있는 창을 두고 대화하세요 | 궁금한 창이나 차트 구간, 표의 항목을 짚어 질문하세요. AI가 같은 자료를 바라보며 의미를 설명하고, 다른 결과와 비교해줍니다. | 차트의 선택 구간이 대화 참조로 붙고 “이 구간에서 거래량은 어땠어?”에 답하는 장면 |
| Q3 | 주문도 대화로 시작하세요 | 종목과 수량, 원하는 가격을 말하면 주문 티켓이 만들어집니다. “수량만 줄여줘”처럼 조건을 다듬고, 내용을 확인한 뒤 실행하세요. | 자연어 요청 → 주문 티켓 → 대화로 수량 변경 → 최종 확인 |

| ID | 제목 | 소개 문구 | 아이콘 방향 |

| QS1 | 내 자료를 질문에 함께 | 파일을 첨부하거나 폴더를 지정해, 내 자료를 바탕으로 질문하세요. | 폴더와 말풍선 |
| QS2 | 상황에 맞는 대화 모드 | 목표 모드와 계획 모드 등 상황에 맞는 모드를 선택해 질의응답하세요. | 목표점과 경로 |
| QS3 | 모델과 사고 정도 조절 | 여러 AI 모델 중 원하는 모델을 선택하고, 질문에 맞게 사고 정도를 조절하세요. | 모델 분기와 단계 표시 |

이전 요청에서 확정한 아고라 서브 3개는 유지한다. 메인의 창 참조는 구간·항목 질문과 비교까지 구체화했다.

## 3. 메티스 — 내 지식으로 대화하는 AI

**헤드라인: 내가 보고, 묻고, 선택한 모든 것이 나를 아는 AI가 됩니다.**

메티스는 대화뿐 아니라 앱에서 한 모든 활동을 기록하고 지식 그래프로 연결합니다. 열어본 차트, 비교한 종목, 설정한 알람, 백테스트한 전략까지 내 맥락으로 쌓입니다. AI는 이 그래프를 바탕으로 답하고 나에게 맞는 다음 탐색을 추천합니다. 마치 내가 가진 지식을 함께 펼쳐놓고 대화하는 것처럼요.

### 메인 4개

| ID | 제목 | 소개 문구 | 큰 이미지에 담을 장면 |
|---|---|---|---|
| M1 | 앱에서 한 모든 활동이 내 지식으로 쌓입니다 | 대화, 조회, 비교, 감시 설정, 전략 실험과 결과 확인까지 기록합니다. 요약 뷰에서 내가 무엇에 관심을 두고 어떤 판단을 해왔는지 한눈에 돌아보세요. | 요약 뷰에 대화·차트 조회·알람 설정·백테스트 기록이 함께 모이고, 관련 관심 주제로 연결되는 모습 |
| M2 | 흩어진 기록이 하나의 지도로 이어집니다 | 기본 군집 지도에서 종목과 테마, 내 판단과 활동의 연결을 펼쳐보세요. 관심 있는 군집을 열면 그 안의 기록과 다른 주제로 이어지는 관계까지 드러납니다. | 기본 군집 지도 → 선택 군집의 내부 관계와 주변 군집으로 이어지는 연결 |
| M3 | 내 지식을 함께 펼쳐놓고 대화합니다 | 노드를 고르고 “내가 이 종목을 왜 지켜봤지?”라고 물어보세요. 이전 대화와 분석, 실험 결과를 함께 짚어주어, 매번 배경을 다시 설명하지 않고도 생각을 이어갈 수 있습니다. | 선택 노드 패널에 이전 질문·관련 차트·전략 실험이 보이고 그 근거로 대화하는 모습 |
| M4 | 나를 이해한 추천이 다음 탐색으로 이어집니다 | AI가 그래프에 쌓인 관심사와 판단, 최근 활동을 바탕으로 나에게 맞는 자료와 비교 대상, 다음 질문을 제안합니다. 무엇을 추천했는지와 함께 왜 지금 나에게 필요한지도 보여줍니다. | 추천 카드 옆에 “최근 비교한 주제”, “이전에 확인한 위험”, “아직 살펴보지 않은 연결”이 그래프 경로로 표시됨 |

### 서브 5개

| ID | 제목 | 소개 문구 | 아이콘 방향 |
|---|---|---|---|
| MS1 | 관심사 사이의 뜻밖의 연결 | 따로 살펴보던 종목과 주제 사이에서 공통 기업, 사건, 공급망처럼 놓쳤던 연결을 찾아줍니다. | 두 군집을 잇는 선 |
| MS2 | 결론까지 이어진 생각의 이력 | 처음 관심을 가진 이유부터 비교와 실험을 거쳐 생각이 달라진 순간까지, 판단이 만들어진 과정을 되짚어줍니다. | 시간축 위의 분기 |
| MS3 | 추천마다 따라오는 나만의 근거 | 추천의 출발점이 된 내 활동과 관련 자료를 함께 보여줘, 그 제안이 내 상황에 맞는지 판단할 수 있습니다. | 추천 카드와 근거 경로 |
| MS4 | 기록된 사실과 AI의 해석을 구별 | 실제 활동에서 확인된 내용과 AI가 추론한 관계를 나누고, 아직 확인할 부분은 질문으로 짚어줍니다. | 사실·해석 두 겹의 노드 |
| MS5 | 대화하며 더 정확해지는 기억 | “그건 관심이 아니라 비교용이었어”라고 알려주세요. 잘못 읽힌 맥락을 바로잡아 다음 대화와 추천에 반영합니다. | 수정되는 관계선 |

**대표 대화:** “지난번에 배당보다 현금흐름을 먼저 보겠다고 했지. 그 기준으로 아직 살펴보지 않은 자료를 추천해줘.” 메티스는 해당 판단이 나온 대화와 이후 조회·실험을 함께 읽고, 추천의 이유를 보여준다.

**기록의 구체적 범위:** 대화와 첨부 자료 사용, 차트·문서 조회, 종목 비교, 관심 대상 선택, 알람·감시 설정, 도구 사용, 전략 생성·수정·백테스트, 결과 확인, 추천에 대한 선택과 정정을 작업 이력으로 연결한다. 단순 목록을 쌓는 데서 끝나지 않고 **어떤 관심에서 어떤 행동으로 이어졌는지**를 보존하는 것이 핵심이다.

## 4. 아이기스 — 나를 이해하고 변화를 지켜보는 AI

**헤드라인: 내 관심사를 아는 감시. 조건은 말로만 정하세요.**

메티스의 지식 그래프를 바탕으로 나에게 중요한 변화를 찾아 알립니다. 원하는 조건을 말하면 키움 REST API와 에르가네에 연결한 MCP 도구를 조합해 감시를 구성합니다. 정해진 시간의 반복 작업부터 여러 데이터가 함께 충족되는 조건까지, 대화로 맡기세요.

### 메인 3개

| ID | 제목 | 소개 문구 | 큰 이미지에 담을 장면 |
|---|---|---|---|
| A1 | 나를 아는 그래프가 맞춤 알람이 됩니다 | 메티스에 쌓인 관심 종목, 분석 주제, 이전 판단을 바탕으로 나에게 중요한 변화를 알려줍니다. 알람에는 발생한 사건과 함께 내 어떤 관심사에 연결되는지도 담깁니다. | 알람 센터의 사건 카드와 메티스의 관련 관심 노드·과거 판단이 연결된 모습 |
| A2 | 대화형 감시·작업 자동화 | 여러 감시 조건과 작업 일정을 대화로 설정하고 수정하세요. AI가 정해진 시간이나 조건이 충족된 순간에 자료를 모으고 분석해 결과를 전달합니다. | 대화 → 감시 규칙·작업 일정 → 조건 충족·도구 실행 → 분석 결과 |
| A3 | 키움 REST API·MCP 통합 감시 | 키움 REST API와 에르가네에서 지정한 모든 MCP 서버의 조회 결과를 조건으로 활용하세요. 시세 변화와 새 공시, 외부 문서의 갱신처럼 서로 다른 데이터의 조건도 하나의 대화로 연결합니다. | 키움의 시장 데이터와 MCP 공시·문서 도구가 한 조건 흐름으로 모이는 화면 |

### 서브 3개

| ID | 제목 | 소개 문구 | 아이콘 방향 |
|---|---|---|---|
| AS1 | 과거에 대입해 보는 감시 조건 | 만든 조건이 과거 데이터에서는 언제 충족됐는지 미리 살펴보고, 너무 자주 울리거나 중요한 변화를 놓치지 않도록 다듬으세요. | 알람과 과거 시간축 |
| AS2 | 같은 사건은 하나의 알람으로 | 여러 도구에서 들어온 신호가 같은 사건을 가리키면 하나로 묶고, 새로 달라진 내용과 내게 미치는 관련성을 정리해 알려줍니다. | 여러 신호가 모인 카드 |
| AS3 | 내 피드백으로 정교해지는 알람 | “이 정도 변화는 묶어서 알려줘”, “이 주제는 바로 알려줘”라고 말하세요. 내가 중요하게 여기는 기준에 맞춰 알림의 우선순위와 전달 방식을 조정합니다. | 피드백과 중요도 표시 |

**대표 대화:** “관심 종목의 거래량이 평소보다 크게 늘고, 연결한 공시 도구에 새 공시가 나오면 두 내용을 묶어서 알려줘. 내가 전에 중요하게 본 사업과 관련 있는지도 설명해줘.”

**메티스와의 역할 연결:** 메티스는 관심과 판단을 기억해 추천의 맥락을 만든다. 아이기스는 그 맥락과 사용자가 말한 조건을 실제 감시에 사용하고, 시점이 있는 알람과 작업 결과를 만든다. AS1은 알림 조건의 과거 발생 빈도를 점검하는 경험이며, 투자 전략의 매매 성과를 검증하는 팔라스와 목적이 다르다.

## 5. 에르가네 — 모든 모드로 이어지는 MCP 확장

**헤드라인: 원하는 MCP를 연결하고, 모든 모드를 내 방식으로.**

에르가네는 투자정보부터 외부 서비스까지 원하는 MCP를 연결해 Athena의 모든 모드에서 활용하는 확장 공간입니다. 시세와 뉴스를 받아보고 디스코드와 연동하며, 나만의 도구 조합으로 각 모드의 활용 방식을 넓힐 수 있습니다.

### 메인 3개

기존 서브의 위치 이동, 펼치기, 질문 중단, 전체 화면 이동은 삭제했다. 미니 주문 티켓은 실제 사용 가치가 드러나도록 다시 쓰고, 신규 2개를 더해 서브를 3개로 구성했다.

## 9. 조사 근거와 이번 기획의 관계

이 표는 제작팀을 위한 범위 기록이다. 앞의 제품 소개 문구에는 구현 상태를 반복해 넣지 않는다. 사용자가 지정한 방향과 이번 신규 아이디어는 **완성될 경험의 약속**이며, 기존 코드 조사 결과와 동일한 증거로 취급하지 않는다.

| 제품 | 기존 조사에서 확인한 기반 | 이번 사용자 지정으로 강조한 내용 | 이번 원고에서 확장한 아이디어 |
