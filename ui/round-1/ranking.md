### A — Nocturnal Glass
`#08090C` × 자수정 `#C6A2FF` · Inter / Geist Mono

무드보드에 가장 충실한 안. 인터랙티브 창 전체가 하나의 유리 패널이고, 그 안에 캔버스가 유리 조각으로 들어앉는다. 커맨드바는 하단 독립 표면, 포커스 링이 자수정으로 발광.

- **의도**: 리퀴드 글래스를 문자 그대로 구현. 빛이 데이터(차트 라인)에서 나와 유리 가장자리를 물들이는 구조.
- **위험**: 자수정 = `charcoal × electric purple`. 2019–2024 SaaS에서 가장 소모된 조합. §7 "AI 냄새" 정면 리스크.
- **캔버스 계층**: 창(유리) > 캔버스(유리) > 행 — 2단 중첩. 캔버스를 3개 이상 넣으면 유리가 겹쳐 탁해질 수 있음.

### B — Instrument Amber
`#0B0B0C` × 앰버 LED `#FF9F1C` · Geist / Geist Mono / IBM Plex Sans KR

유리 패널을 전부 걷어냈다. 카드가 없다. 정보가 검은 표면 위에 직접 올라가고, 구획은 1px 헤어라인뿐. **유채색은 앰버 단 하나** — 등락조차 빨강/파랑을 쓰지 않고 앰버 + 부호로 표현. 132px 숫자가 화면을 지배.

- **의도**: "색깔을 싹 다 빼고 제일 중요한 버튼 딱 하나만 색깔이 있다"는 테슬라 철학의 문자 그대로의 번역.

## 라운드 1 이후 확정된 것 (채점 대상 아님)

무드보드 정독과 Apple 규범 검토로 **디자인이 아니라 근거로 결정된** 항목이다. 시안 점수와 무관하게 확정.

| 질문 | 답 | 근거 |
|---|---|---|
| 캔버스를 유리로 박는가 | **아니다. 불투명하다** | [liquid-glass.md](../liquid-glass.md) §2 — 콘텐츠 레이어에 유리 금지, 유리 위 유리 금지 |
| 유리는 어디에 쓰는가 | **커맨드바 하나뿐** | 같은 문서 §5 — 내비게이션 레이어 = 커맨드바 |
| 유리 뒤의 환경은 무엇인가 | **데이터 캔버스 자체** | [moodboard.md](../moodboard/moodboard.md) 1순위 DNA + 성능 제약의 교집합 |
| 커맨드바는 창 아래 여백에 놓이는가 | **아니다. 콘텐츠 위에 뜬다** | 뒤에 굴절될 것이 없으면 유리일 이유가 없다 |

**→ A안의 "인터랙티브 창도 유리, 캔버스도 유리" 구조는 폐기.** 라운드 1의 4안 중 재료를 옳게 쓴 안은 없다.

## 라운드 1이 여전히 결정해야 할 것

시안을 다 보고 나면 아래에 답이 나와 있어야 한다. 답이 안 나오면 라운드 2를 돌 자격이 없다.

1. **다크인가 라이트인가** — D를 탈락시키는가, 살리는가
   *(주의: 리퀴드 글래스가 핵심이므로 D는 재료 축에서 이미 불리하다. 그래도 "장시간 보는 트레이딩 앱에 흰 배경"이라는 논점 자체는 살아 있다)*
2. **커맨드바는 위인가 아래인가** — C 대 나머지
3. **등락을 빨강/파랑으로 쓰는가** — B(안 씀) 대 A·C·D(씀)
4. **불투명 콘텐츠 레이어의 위계를 무엇으로 만드는가** — 카드 경계(A) / 헤어라인(B·C) / 굵은 흑선(D)
   *(Apple: 유리를 못 쓰는 콘텐츠 레이어는 fill·transparency·vibrancy로 위계를 만든다)*
5. **액센트 색 하나** — 자수정 / 앰버 / 인광 / 없음
